# fuzzy-winner：机器人学习与知识积累

本仓库用于持续保存机器人与具身智能相关的学习代码、项目文档、知识笔记，以及用户和协作者已经明确形成的共识。

当前从机器人软件与系统开发方向开始探索，采用项目驱动、理解模块与接口、仿真先行的学习方式。具体机器人项目、载体和运行环境尚未选定。

## 新会话从这里接手

先按顺序读取：

1. [AGENTS.md](AGENTS.md)：用户偏好、讲解方式与协作规则。
2. [PROJECT_STATUS.md](PROJECT_STATUS.md)：当前进度、验证情况与下一步。
3. [docs/architecture.md](docs/architecture.md)：仓库结构和模块分析规范。
4. [docs/consensus.md](docs/consensus.md)：已经明确的共识及仍待验证的判断。

## 内容入口

| 位置 | 用途 |
| --- | --- |
| [projects/](projects/README.md) | 实际学习项目、示例代码及各自的构建和运行说明。 |
| [notes/](notes/README.md) | 可复用知识、问题排查、接口理解和实践记录。 |
| [docs/](docs/architecture.md) | 整体说明、结构、接口与共识文档。 |

项目代码放在 `projects/<项目名>/`，每个项目独立说明依赖、环境、启动方法、模块和验证结果。当前只有资料骨架，没有已经完成的机器人程序。

## 如何持续积累

- 将一次讨论整理为可独立理解的结论，保留适用条件和必要来源。
- 将“用户已确认”“建议”“待验证”“已运行验证”区分记录。
- 项目有实质进展时更新状态文件，结构或接口变化时更新对应文档。
- 通过 Git 提交和推送保存版本；本地改动不会自动出现在 GitHub。
- 本仓库当前公开，发布内容以经过整理的项目资料为范围；密钥、个人敏感资料、其他无关项目和完整私人会话不纳入默认上传内容。
