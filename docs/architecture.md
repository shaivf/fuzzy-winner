## 文档职责

| 文档 | 记录内容 |
| --- | --- |
| `AGENTS.md` | 新会话必读规则、讲解方式与协作约定。 |
| `PROJECT_STATUS.md` | 当前阶段、已验证事实、未知项与下一步。 |
| `docs/consensus.md` | 已确认共识、适用范围和后续修正。 |
| `notes/` 下的笔记 | 可以复用的知识、排查经验与验证过程。 |
| 各项目的 README 和架构说明 | 环境、启动方式、真实模块、接口与任务流程。 |

## 理解一个模块时记录什么

- **职责与边界**：负责解决什么问题，哪些职责属于其他模块。
- **实现思路**：主要处理步骤，使用哪些算法、库、模型或服务，分别发挥什么作用。
- **接口契约**：输入输出、数据类型与含义、调用条件；按需说明单位、坐标系、时间戳或频率。
- **依赖与生命周期**：调用方、依赖方、启动顺序、配置与就绪条件。
- **状态与故障**：成功、失败、取消、超时等适用行为，以及日志和恢复入口。
- **源码与证据**：真实文件位置、关键类或函数；明确是文档描述、源码追踪还是实际运行过的结论。

## 说明一条完整任务时记录什么

从任务发起者和输入开始，逐步说明经过哪些模块、每一步怎样处理数据、通过什么接口传递，以及最终如何返回结果。补充适用的失败、取消和超时路径，并链接到源码、配置或验证记录。

先理解整体和主要流程，随后按问题深入；必要时用小规模修改或运行观察验证理解，不默认逐行讲解整个仓库。
